# 🧮 Calculadora

Projeto de uma **calculadora desenvolvido para fins de estudo**, utilizando apenas **HTML e CSS**.

Neste momento, o projeto possui somente a **estrutura e a interface visual** da calculadora. As operações e demais interações ainda serão implementadas com JavaScript.

## 🎯 Objetivo

O projeto foi criado para praticar:

* Estruturação de páginas com HTML
* Estilização e criação de interfaces com CSS
* Organização de arquivos e código
* Desenvolvimento gradual de um projeto

## 🚧 Status

**Em desenvolvimento.**

Atualmente, a calculadora **não possui funcionalidades ou interações**, sendo apenas a representação visual da interface.

### Próximos passos

* [ ] Adicionar JavaScript
* [ ] Implementar operações matemáticas
* [ ] Adicionar interação aos botões
* [ ] Melhorar a interface e responsividade

## 🛠️ Tecnologias

* HTML5
* CSS3
